Can you explain how streaming works in this app?
Sure! Here's how streaming works in this chatbot: 1. You send a message, which gets POSTed to /api/chat along with the full conversation history 2. The server calls OpenAI's API with stream=True 3. As GPT generates each token, the server sends it as a Server-Sent Event (SSE) 4. The browser reads these tokens in real-time using fetch + ReadableStream 5. Each token is appended to the assistant's message bubble as it arrives This gives you that satisfying "typing" effect where the response appears word by word, instead of waiting for the entire response to finish.
